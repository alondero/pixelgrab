## Decisions

The intended CLAUDE symlink was absent and Windows denied symlink creation
without elevation. Use a portable forwarding file with one canonical AGENTS
source; retain checker support for symlinks and Git placeholder checkouts.

Use one portable change/review skill rather than duplicate personal diagnosis,
review, and finish skills. The workflow can run sequentially and requires no
missing setup plugin or parallel-agent capability. Scope review to the actual
user request and a recorded Git base; do not stop to ask for an obvious local
diff base. Personal finish instructions cannot authorize publication.

Use CI for enforcement and an optional Git hook for early feedback. Agent-specific
stop hooks would duplicate checks, depend on client configuration, and risk
blocking ordinary conversation. The fast checker checks structural drift only;
meaningful tests and human/agent review still own correctness.
